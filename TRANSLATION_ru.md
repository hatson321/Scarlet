# Scarlet — Russian translation (Русский перевод)

A full bilingual translation of the user-facing strings from `TRANSLATION.md`, English → Russian.
Duplicated strings are translated once; pure code fragments (e.g. `+key+`, font names, HTML tags,
already-keyed references) are omitted. Uses standard Russian software conventions.

> Демонстрационный перевод. Термины модерации (бан/кик/предупреждение) стоит проверить носителю.
